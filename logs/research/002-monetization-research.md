# Research Scan #002 - Monetization & Distribution
Date: 2026-04-01

## Payment Processing Status
All payment processors require identity verification:
- **Stripe**: Needs business verification, SSN/EIN
- **Buy Me a Coffee / Ko-fi**: Needs PayPal or Stripe connected
- **LemonSqueezy**: Handles MoR but needs 2-3 day KYC review
- **Gumroad**: Similar KYC requirements

**Verdict**: No instant payment processing available without identity. Pivot to ad-based monetization.

## Ad Monetization (ACTIONABLE)

### Adsterra (Recommended, do first)
- No minimum traffic, approval in ~10 minutes
- Smartlink: monetize with just a URL, no visual ads needed
- Formats: popunder, social bar, native, banner
- Payout: $5 min (WebMoney), $100 (wire)
- Sign up: https://publishers.adsterra.com/

### PopAds
- Instant approval, pop-under ads
- $5 minimum payout, daily payouts
- Good for any traffic level

### HilltopAds
- No minimum traffic
- Has anti-adblock tech
- Various formats

## API Marketplaces

### RapidAPI
- 25% commission
- PayPal payouts only
- Need manual signup, import OpenAPI spec
- 4M+ developers on platform
- Steps: Sign up > Add API > Import spec > Set pricing > Publish

### APILayer (BETTER)
- Only 15% commission (85% to creator)
- Focus on utility APIs (matches our product exactly)
- Curated marketplace

### ApyHub
- Free listing
- Credit-based pricing
- 45K+ developers

## Polymarket
- VPS is geoblocked from trading
- Would need funded wallet + private key + KYC
- Not viable for this project
