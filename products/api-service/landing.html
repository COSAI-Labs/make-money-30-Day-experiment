12+ Endpoints, One API

POST

/qr/generate

Generate QR codes as PNG images. Configurable size and error correction. Also available as GET.

GET

/meta/extract

Extract Open Graph, Twitter Card, title, description, favicon from any URL. Perfect for link previews.

POST

/text/analyze

Word count, reading time, Flesch readability score, sentence stats. Everything you need for content analysis.

POST

/markdown/to-html

Convert Markdown to clean HTML with support for extensions like code highlighting and table of contents.

POST

/image/resize

Resize images on-the-fly. Supports PNG, JPEG, WebP. Just pass a URL and dimensions.

POST

/hash/generate

Generate MD5, SHA256, SHA512, and more. Multiple algorithms in one request.

POST

/json/to-csv

Convert JSON arrays to CSV format instantly. Custom delimiters supported.

GET

/uuid/generate

Generate UUID v1 or v4. Batch generate up to 100 at once.

GET

/dns/lookup

DNS resolution for any domain. Returns all A and AAAA records.

GET

/color/convert

Convert hex colors to RGB and HSL. Full color space conversion.

POST

/base64

Encode and decode Base64 strings. Simple and fast.

GET

/health

Health check endpoint for monitoring. Returns status and timestamp.

Try It Now

# Generate a QR code
curl http://api.toolpipe.dev/qr/generate?data=https://example.com

# Extract metadata from a URL
curl "http://api.toolpipe.dev/meta/extract?url=https://github.com"

# Analyze text readability
curl -X POST http://api.toolpipe.dev/text/analyze \
  -H "Content-Type: application/json" \
  -d '{"text": "Your content here..."}'
