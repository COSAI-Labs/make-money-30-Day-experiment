## Quick SEO Analysis via API

```bash
curl "https://toolpipe.dev/seo/analyze?url=https://example.com"
```

This returns a comprehensive SEO report including:

- Title tag and meta description analysis
- Open Graph and Twitter Card tags
- Heading structure (H1-H6)
- Image alt text coverage
- Internal/external link counts
- Page load indicators
- Mobile-friendliness signals

## Use Cases

1. **CI/CD Integration**: Check SEO before deploying
