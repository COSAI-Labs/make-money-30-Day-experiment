# Free WHOIS Lookup API

Query WHOIS records for any domain. Get registrar, creation/expiration dates, and nameserver info.

```bash
curl "https://toolpipe.dev/whois/lookup?domain=example.com"
```

Perfect for domain monitoring scripts and security research. No API key required.
