# Free XML to JSON Converter API

Convert XML to JSON with a single API call. Handles nested structures, attributes, and repeated elements.

```bash
curl -X POST https://toolpipe.dev/convert/xml-to-json \
  -H "Content-Type: application/json" \
  -d '{"xml": "<users><user><name>Alice</name></user></users>"}'
```
