# Free Text Summarizer API

Summarize long text into key points with a single API call. Extractive summarization that pulls the most important sentences.

```bash
curl -X POST https://toolpipe.dev/text/summarize \
  -H "Content-Type: application/json" \
  -d '{"text": "Your long article text here...", "sentences": 3}'
```

Configurable summary length. Free, no API key.
