# Free Keyword Extractor API

Extract keywords and key phrases from any text using TF-IDF based analysis. Get relevance scores for each keyword.

```bash
curl -X POST https://toolpipe.dev/text/keywords \
  -H "Content-Type: application/json" \
  -d '{"text": "Your content for keyword extraction..."}'
```

Multi-word phrase detection. Relevance scoring. Free REST API, no signup needed.
