Need to generate color palettes programmatically? ToolPipe has a free API for that.

## Quick Start

```bash
curl "https://toolpipe.dev/color/palette?base=%23FF6B6B&count=5"
```

## Features

- Generate from any base color
- Complementary, analogous, triadic, split-complementary schemes
- Returns HEX, RGB, and HSL values
- Perfect for design systems and data visualization

## No Signup Required

Free, no API key needed. Part of 70+ developer APIs at [toolpipe.dev](https://toolpipe.dev).
