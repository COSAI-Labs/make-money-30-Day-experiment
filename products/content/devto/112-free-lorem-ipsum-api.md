Generate placeholder text for your prototypes via REST API.

## Quick Start

```bash
curl "https://toolpipe.dev/lorem/generate?paragraphs=3&format=text"
```

## Options

- Paragraphs, sentences, or words
- Custom count and length
- Plain text or HTML output
- Start with "Lorem ipsum" or random

Perfect for UI prototyping, database seeding, and email template testing.

Free at [toolpipe.dev](https://toolpipe.dev) - no signup, no API key needed.
