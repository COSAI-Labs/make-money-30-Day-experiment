## Analyze CSV Data via API

Upload CSV data and get statistical analysis: column types, distributions, correlations, outliers, and summary stats.

```bash
curl -X POST https://toolpipe.dev/csv/analyze \
  -H "Content-Type: text/csv" \
  -d 'name,age,score
John,25,95
Jane,30,87
Bob,22,91'
```

No data retained after processing. Perfect for quick data exploration. No signup required.
