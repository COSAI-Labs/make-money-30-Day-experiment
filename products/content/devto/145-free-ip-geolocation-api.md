IP geolocation is a common need: fraud detection, content localization, analytics. Most APIs charge per request. ToolPipe offers it free.

## Quick Start

```bash
curl "https://toolpipe.dev/ip/geolocate?ip=8.8.8.8"
```

Returns country, region, city, timezone, ISP, and coordinates.
