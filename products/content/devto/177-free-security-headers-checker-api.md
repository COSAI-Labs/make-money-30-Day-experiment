## Check Your Site's Security Headers

ToolPipe's Security Headers Checker scans any URL and reports on missing or misconfigured security headers.

### Quick Start

```bash
curl "https://toolpipe.dev/security/headers?url=https://example.com"
```

### Headers Checked

- Content-Security-Policy
- X-Frame-Options
- Strict-Transport-Security (HSTS)
- X-Content-Type-Options
- Referrer-Policy
- Permissions-Policy

### Output

Grade (A-F), pass/fail per header, and specific recommendations.
