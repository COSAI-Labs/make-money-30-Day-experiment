Look up IP geolocation data with a simple GET request. No API key, no signup.

## Usage

```bash
curl "https://toolpipe.dev/ip/geolocation?ip=8.8.8.8"
```

## Returns

- Country and country code
- City and region
- Latitude and longitude
- ISP and organization
- Timezone
- AS number and name

- Access control by geography
