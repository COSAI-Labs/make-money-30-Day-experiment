# Free IP Geolocation API

Need to determine a user's location from their IP address? ToolPipe offers a free IP geolocation API with no signup required.

## Quick Start

```bash
curl "https://toolpipe.dev/ip/geo?ip=8.8.8.8"
```

Returns JSON with country, city, region, latitude, longitude, timezone, and ISP data.

## Use Cases

- Geo-targeting content and ads
- Fraud detection by verifying user location
- Analytics dashboards showing visitor geography
- Compliance checks for region-restricted content

## Response Format

The API returns structured JSON including:
- Country and country code
- City and region
- Latitude and longitude
- Timezone
- ISP and organization
