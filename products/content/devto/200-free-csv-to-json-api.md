# Free CSV to JSON Converter API

Convert CSV data to JSON and back via a simple REST API call. No signup, no API key.

## Quick Start

```bash
curl -X POST https://toolpipe.dev/csv/to-json \
  -H "Content-Type: application/json" \
  -d '{"csv": "name,age\nAlice,30\nBob,25"}'
```

Returns a JSON array of objects with automatic header detection.

## Also Available

- JSON to CSV: `POST /json/to-csv`
- XML to JSON: `POST /xml/to-json`
- YAML to JSON: `POST /yaml/to-json`

## Why Use an API?

- Integrate into CI/CD pipelines without library dependencies
- Process data in serverless functions
- Works from any language with HTTP support
- No need to parse CSV manually
