# Free Slug Generator API

Generate URL-friendly slugs from any text via a REST API. No signup required.

## Quick Start

```bash
curl -X POST https://toolpipe.dev/slug/generate \
  -H "Content-Type: application/json" \
  -d '{"text": "My Amazing Blog Post Title!"}'
```

Returns: `my-amazing-blog-post-title`

## Features

- Unicode support for accented characters
- Special character removal
- Configurable separator
- Lowercase normalization
- Handles multiple spaces and dashes

## Use Cases

- CMS and blog platforms
- E-commerce product URLs
- SEO-friendly URL generation
- Dynamic route creation
