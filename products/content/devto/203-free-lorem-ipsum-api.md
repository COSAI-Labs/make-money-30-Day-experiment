# Free Lorem Ipsum Generator API

Generate placeholder text programmatically. Customize paragraphs, sentences, and words via REST.

## Quick Start

```bash
curl -X POST https://toolpipe.dev/lorem/generate \
  -H "Content-Type: application/json" \
  -d '{"paragraphs": 3, "type": "paragraphs"}'
```

## Options

- Generate paragraphs, sentences, or words
- Custom count for each type
- Standard Lorem Ipsum text
- JSON response format
