# Free HTTP Status Code Checker API

Check HTTP status codes and response headers for any URL. Free REST API, no signup.

## Quick Start

```bash
curl "https://toolpipe.dev/http/check?url=https://example.com"
```

## Response Data

- HTTP status code and message
- Response time in milliseconds
- Response headers
- Redirect chain (if any)
- SSL certificate status

## Use Cases

- Uptime monitoring scripts
- Link checking and validation
- SEO auditing tools
- API health checks in CI/CD
