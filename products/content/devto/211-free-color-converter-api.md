## Free Color Conversion API

Convert colors between HEX, RGB, and HSL formats with a simple GET request.

### Endpoint

```
GET https://toolpipe.dev/color/convert?hex=FF5733
```

### Response

Returns RGB, HSL, and CSS-ready format strings for the given hex color.

### Example

```bash
curl "https://toolpipe.dev/color/convert?hex=3498DB"
```

- Design system tooling

- CSS-in-JS color manipulation
