## Free Changelog Generator API

Generate professional changelogs from commit data or release notes.

### Endpoint

```
POST https://toolpipe.dev/api/changelog/generate
```

### Features

- Keep a Changelog format compliance
- Semantic versioning support
- Categorized entries: Added, Changed, Fixed, Removed
- Multiple output formats

No signup required. Part of 240+ free tools at [toolpipe.dev](https://toolpipe.dev).
