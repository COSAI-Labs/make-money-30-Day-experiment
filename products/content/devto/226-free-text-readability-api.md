## Free Text Readability Score API

Analyze text readability with Flesch-Kincaid, Gunning Fog, and other scores.

### Endpoint

```
POST https://toolpipe.dev/api/text/readability
```

### Metrics

- Flesch Reading Ease score
- Flesch-Kincaid Grade Level
- Gunning Fog Index
- Word, sentence, and syllable counts
- Average words per sentence

### Use Cases

- Content quality gates in CMS
- Automated writing feedback
- Documentation readability audits
- SEO content optimization

No signup required. Part of 240+ free tools at [toolpipe.dev](https://toolpipe.dev).
