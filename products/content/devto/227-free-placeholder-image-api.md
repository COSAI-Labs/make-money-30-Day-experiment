## Free Placeholder Image Generator API

Generate placeholder images of any size with a simple GET request. No API key needed.

### Endpoints

```
GET https://toolpipe.dev/api/placeholder/300
GET https://toolpipe.dev/api/placeholder/800x600
```

### HTML Usage

```html
<img src="https://toolpipe.dev/api/placeholder/400x300" alt="placeholder">
```

### Use Cases

- Wireframe mockups
- Development placeholders
- Email template testing
- Documentation examples

No signup required. Direct URL. Part of 240+ free tools at [toolpipe.dev](https://toolpipe.dev).
