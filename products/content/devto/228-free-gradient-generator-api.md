## Free CSS Gradient Generator API

Generate CSS gradient code programmatically.

### Endpoint

```
POST https://toolpipe.dev/api/gradient
```

### Example

```bash
curl -X POST https://toolpipe.dev/api/gradient \
  -H "Content-Type: application/json" \
  -d '{"colors": ["#ff6b6b", "#4ecdc4"]}'
```

### Features

- Linear and radial gradients
- Custom color stops
- CSS output ready to use
- Multiple format support

No signup required. Part of 240+ free tools at [toolpipe.dev](https://toolpipe.dev).
