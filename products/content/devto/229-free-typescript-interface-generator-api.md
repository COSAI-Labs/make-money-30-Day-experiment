Stop manually writing TypeScript interfaces for your JSON data. ToolPipe's free API generates them automatically.

## Quick Start

```bash
curl -X POST https://toolpipe.dev/api/generate/typescript-interface \
  -H "Content-Type: application/json" \
  -d '{"json": {"name": "John", "age": 30, "active": true}}'
```

Returns a proper TypeScript interface with correct types inferred from your JSON.

- Automatic type inference
