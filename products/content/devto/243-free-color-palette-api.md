## Generate Color Palettes Programmatically

Need to convert colors between formats or generate harmonious palettes? ToolPipe's Color API does it all.

### Endpoint

```
GET https://toolpipe.dev/color/convert?color=%23FF5733&format=all
```

### Features

- HEX to RGB, HSL, and back
- Complementary color generation
- Analogous and triadic schemes
- Contrast ratio calculation (WCAG compliance)

Free: 100 calls/day. Part of 70+ free APIs at [ToolPipe](https://toolpipe.dev).
