## Convert CSV to JSON via REST API

Upload CSV data and get structured JSON back. Auto-detects delimiters and header rows.

### Endpoint

```
POST https://toolpipe.dev/api/convert/csv-to-json
```

### Features

- Auto-detect delimiters (comma, tab, semicolon, pipe)
- Header row detection
- Type inference (numbers, booleans, dates)
- Large file support
