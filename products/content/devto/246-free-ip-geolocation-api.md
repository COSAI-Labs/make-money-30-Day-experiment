## Look Up Any IP Address

Get geolocation data for any IP address without an API key.

### Endpoint

```
GET https://toolpipe.dev/ip/lookup?ip=8.8.8.8
```

### Returns

- Country, region, city
- Latitude/longitude coordinates
- ISP and organization
- Timezone
- Your own IP: `GET /ip/my`
