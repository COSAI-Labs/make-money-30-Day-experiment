## Generate SEO-Friendly URL Slugs

Convert any text into clean URL slugs. Handles Unicode, special characters, and multi-language text.

### Endpoint

```
POST https://toolpipe.dev/api/slug/generate
```

### Features

- Unicode transliteration
- Custom separator support
- Max length truncation
- Duplicate character removal

Free: 100 calls/day. Part of 70+ APIs at [ToolPipe](https://toolpipe.dev).
