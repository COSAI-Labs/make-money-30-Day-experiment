# Free IP Geolocation API

Look up geographic location, ISP, and country data for any IP address. No API key needed.

## Quick Start

```bash
# Look up an IP
curl https://toolpipe.dev/ip/lookup?ip=8.8.8.8

# Get your public IP
curl https://toolpipe.dev/ip/my
```

## Response Data

- Country, region, city
- ISP and organization
- Timezone
- Latitude/longitude coordinates
