# Free Cron Expression Parser API

Parse, validate, and get human-readable descriptions of cron expressions via REST API.

## Features

- Parse any cron expression
- Get next N execution times
- Human-readable descriptions ("Every Monday at 9:00 AM")
- Validate cron syntax
- Supports standard 5-field and extended 6-field formats

## Use Cases

- Cron schedule validation in CI/CD pipelines
- Displaying human-readable schedules in admin dashboards
- Testing cron expressions before deploying
- Building scheduler UIs
