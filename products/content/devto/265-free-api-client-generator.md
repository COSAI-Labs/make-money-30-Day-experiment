# Free API Client Generator

Generate API client code from OpenAPI/Swagger specs. Supports JavaScript, Python, TypeScript, and more.

## How It Works

1. Submit your OpenAPI/Swagger specification
2. Choose your target language
3. Get ready-to-use client code

## Supported Outputs

- JavaScript/TypeScript (fetch, axios)
- Python (requests, httpx)
- cURL commands
- And more

## Use Cases

- Quickly scaffold API clients for new integrations
- AI-assisted API integration via MCP
- Documentation and code examples
