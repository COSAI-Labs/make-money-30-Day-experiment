# Free Slug Generator API

Convert any text into URL-friendly slugs. Handles Unicode, special characters, and multiple languages.

## Example

```bash
curl https://toolpipe.dev/slug/generate?text=Hello%20World%21
# Returns: hello-world
```

## Features

- Unicode support (handles accented characters)
- Custom separator options
- Transliteration for non-Latin scripts
- Max length control

## Use Cases

- CMS and blog post URL generation
- E-commerce product URLs
- SEO-friendly URL creation
- Dynamic route generation
