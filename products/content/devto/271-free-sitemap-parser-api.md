Need to parse XML sitemaps for SEO analysis or web crawling? ToolPipe's sitemap parser API extracts all URLs with metadata.

## Usage

```bash
curl "https://toolpipe.dev/api/sitemap/parse?url=https://example.com/sitemap.xml"
```

## Returns

- All URLs in the sitemap
- Last modified dates
- Change frequency
- Priority values

Great for building SEO tools, content audits, or link analysis.
