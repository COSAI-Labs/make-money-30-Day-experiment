Extract Open Graph meta tags from any URL with a single API call.

## Usage

```bash
curl "https://toolpipe.dev/meta/extract?url=https://github.com"
```

Returns title, description, og:image, Twitter Card data, favicon, and canonical URL.

## Use Cases

- Link preview generators
- Social media tools
- SEO analysis
- Content aggregation
