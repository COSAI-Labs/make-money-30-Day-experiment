Merge multiple PDFs into one with ToolPipe's free PDF API.

## Quick Start

```bash
curl -X POST "https://toolpipe.dev/pdf/merge" \
  -F "files=@doc1.pdf" \
  -F "files=@doc2.pdf"
```

## All PDF Tools

- Merge, split, compress
- Watermark, rotate pages
- Password protect
- Extract text

No API key required. Free tier available.
