Resize images programmatically with ToolPipe's free Image API.

## Quick Start

```bash
curl -X POST "https://toolpipe.dev/image/resize" \
  -F "image=@photo.jpg" \
  -F "width=800" \
  -F "height=600"
```

## Image Tools

- Resize to any dimension
- Convert between PNG, JPG, WebP, GIF
- Compress to reduce file size
- Maintain aspect ratio

Perfect for thumbnail generation and responsive image pipelines.
