Generate realistic fake data for testing and development.

## Example

```bash
curl "https://toolpipe.dev/fake/generate?type=person&count=5"
```

Returns JSON array of fake person records with name, email, phone, address.

## Data Types

- Names, emails, phone numbers
- Addresses, cities, countries
- Company names, job titles
- UUIDs, dates, numbers

No signup. No API key. Just call the endpoint.
