# Free CSS Gradient Generator API

Need to generate CSS gradients in your build tools, design systems, or applications? ToolPipe offers a free REST API that creates CSS gradients from color parameters.

## Quick Start

```bash
curl https://toolpipe.dev/css/gradient?type=linear&colors=ff6b6b,4ecdc4
```

Returns ready-to-use CSS gradient code with browser prefixes.

## Features

- **Linear, radial, and conic gradients** with custom directions
- **Multiple color stops** with configurable positions
- **Browser-compatible** CSS output with vendor prefixes
- **No signup or API key** required

## Use Cases

- Theme generators and design system tools
- CSS code generators and preprocessors
- Automated UI testing fixtures
- Color palette applications
