# Free Color Palette Generator API

Generate harmonious color palettes from any base color. ToolPipe provides a free REST API for creating complementary, analogous, and triadic color schemes.

## Quick Start

```bash
curl https://toolpipe.dev/color/palette?base=3498db&count=5
```

Returns color schemes in HEX, RGB, and HSL formats.

## Features

- **Multiple harmony types**: complementary, analogous, triadic, tetradic
- **Output formats**: HEX, RGB, HSL
- **Configurable** palette sizes
- **No signup** required

## Use Cases

- Design system theme generators
- Color accessibility checkers
- Data visualization libraries
- UI prototyping tools
