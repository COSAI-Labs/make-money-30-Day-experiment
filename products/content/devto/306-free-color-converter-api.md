Convert colors between HEX, RGB, HSL, and named formats with ToolPipe's free Color Converter API.

## API Endpoint

```
GET https://toolpipe.dev/color/convert?color=%23ff6600

Response:
{"hex": "#ff6600", "rgb": "rgb(255, 102, 0)", "hsl": "hsl(24, 100%, 50%)", "name": "Blaze Orange"}
```

Perfect for design systems, CSS preprocessing, and color palette tools.

Part of 70+ free developer APIs at [toolpipe.dev](https://toolpipe.dev). No signup required.
