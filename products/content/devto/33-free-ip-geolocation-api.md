Look up geographic location data for any IP address. Free, no signup required.

## Usage

```bash
curl https://toolpipe.dev/ip/geo?ip=8.8.8.8
```

## Response Includes

- Country, region, and city
- Latitude and longitude
- ISP information
- Timezone

## Use Cases

- Analytics and visitor tracking
- Content localization
- Fraud detection
- Access control by region
- Debug network routing
