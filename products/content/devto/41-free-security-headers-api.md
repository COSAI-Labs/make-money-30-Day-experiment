Security headers are your first line of defense. Check any website's security posture with one API call.

```bash
curl "https://toolpipe.dev/security/headers?url=https://example.com"
```

## What it checks:
- Content-Security-Policy
- X-Frame-Options
- X-Content-Type-Options
- Strict-Transport-Security (HSTS)
- Referrer-Policy
- Permissions-Policy
- X-XSS-Protection

Each header gets a pass/fail grade with recommendations for improvement.

## Use Cases
- Pre-deployment security checks
- Competitive security analysis
- Automated compliance monitoring
- Security audit reports
