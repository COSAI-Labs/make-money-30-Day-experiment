Decode JWT tokens from any language or CLI without installing jsonwebtoken.

```bash
curl -X POST https://toolpipe.dev/jwt/decode \
  -H "Content-Type: application/json" \
  -d '{"token": "eyJhbGciOiJIUzI1NiJ9..."}'
```

Returns header and payload as JSON. No signup needed.
