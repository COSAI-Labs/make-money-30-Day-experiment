Convert XML to JSON (and back) via REST. Ideal for ETL and API integrations.

```bash
curl -X POST https://toolpipe.dev/xml/to-json \
  -H "Content-Type: application/json" \
  -d '{"xml": "<root><name>test</name></root>"}'
```

Also available: JSON to YAML, JSON to CSV, YAML to JSON.
