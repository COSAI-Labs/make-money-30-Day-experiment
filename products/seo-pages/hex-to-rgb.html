Color Format Reference

HEX: A 6-digit hexadecimal color code prefixed with #. Example: #ff5733

RGB: Red, Green, Blue values from 0-255. Example: rgb(255, 87, 51)

HSL: Hue (0-360), Saturation (0-100%), Lightness (0-100%). Example: hsl(14, 100%, 60%)
