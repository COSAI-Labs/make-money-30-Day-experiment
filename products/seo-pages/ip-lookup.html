What is an IP Address Lookup?

An IP address lookup reveals the geographic location, Internet Service Provider (ISP), and network information associated with an IP address. Every device connected to the internet has a unique IP address that can be traced to an approximate location.

How to Use This Tool

Enter any IPv4 or IPv6 address in the input field and click "Lookup" to see its details. Click "My IP" to automatically detect and look up your own public IP address. Results include country, city, ISP, coordinates, and timezone information.

API Access

Use this tool programmatically with our free API: GET /api/ip/lookup?ip=8.8.8.8. Returns JSON with geolocation data including country, city, ISP, latitude, longitude, and more.
