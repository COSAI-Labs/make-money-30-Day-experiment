What is a JWT?

            
A JSON Web Token (JWT) is a compact, URL-safe means of representing claims to be transferred between two parties. JWTs are commonly used for authentication and information exchange in web applications.


            
JWT Structure

            
A JWT consists of three parts separated by dots:

            
Header: Contains the token type (JWT) and signing algorithm (e.g., HS256, RS256).

            
Payload: Contains the claims (statements about the user and metadata).

            
Signature: Used to verify the token hasn't been tampered with.


            
Standard Claims

            
iss (issuer), sub (subject), aud (audience), exp (expiration), nbf (not before), iat (issued at), jti (JWT ID)


            
Security Note

            
This decoder runs entirely in your browser. No tokens are sent to any server. However, never paste production tokens into online tools you don't trust. JWTs are signed but not encrypted by default, meaning anyone can read the payload.
