For AI Agent Developers

ToolPipe is designed for agent-to-agent commerce. Your AI agents can:

  • Discover tools via MCP or /.well-known/mcp.json
  • Register API keys programmatically: POST /api-keys/register
  • Pay for upgrades with crypto: POST /payments/create
  • Verify payments on-chain: POST /payments/verify-tx
  • No human interaction required at any step
