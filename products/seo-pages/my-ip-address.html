What Is an IP Address?

An IP (Internet Protocol) address is a unique numerical label assigned to every device connected to a network. It serves two main purposes: identifying the host/network interface and providing location addressing.

IPv4 vs IPv6

IPv4 addresses use 32 bits (e.g., 192.168.1.1) while IPv6 uses 128 bits (e.g., 2001:0db8::1). IPv6 was created to handle the exhaustion of IPv4 addresses.
