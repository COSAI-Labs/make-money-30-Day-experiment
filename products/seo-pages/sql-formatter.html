SQL Formatter

Beautify and format SQL queries online. Supports all major SQL dialects.

Why Format SQL?

Well-formatted SQL queries are easier to read, debug, and maintain. Consistent formatting helps teams collaborate on complex queries and reduces errors in production SQL.

Example

Before formatting:

SELECT u.id,u.name,o.total FROM users u INNER JOIN orders o ON u.id=o.user_id WHERE o.total>100 ORDER BY o.total DESC

After formatting:

SELECT
    u.id,
    u.name,
    o.total
FROM users u
INNER JOIN orders o
    ON u.id = o.user_id
WHERE
    o.total > 100
ORDER BY
    o.total DESC
