What is WHOIS?

            
WHOIS is a protocol for querying databases that store registration information about domain names. It reveals who registered a domain, when it was created, when it expires, and what nameservers it uses.

            
WHOIS Information Includes

            
    
                
  • Registrar name and IANA ID
    • 
                
  • Domain creation, update, and expiry dates
    • 
                
  • Nameservers
    • 
                
  • Domain status (clientTransferProhibited, etc.)
    • 
                
  • Registrant contact (if not privacy-protected)
    • 
            

            
WHOIS API

            
Query WHOIS data programmatically:

            
curl /api/whois?domain=example.com
